# 2. Constitutional Definition (if accepted)

**Reasoning Workspace** is the transient, episode-scoped holding of legal Reasoning artifacts while a Reasoning Episode is active — alternatives, opportunity judgments, predictions, scenarios, simulations, counterfactuals, comparisons, explanations, reflective notes, and option-uncertainty annotations — owned exclusively by Reasoning, destroyed or discarded with the episode unless explicitly cited into a Decision rationale or later promoted through lawful paths (never automatic).

**One sentence:**

> The Workspace is Reasoning’s scratch deliberation field: temporary, scoped, non-authoritative, and incapable of becoming Facts, Understanding, Memory, or Decisions by itself.

**Architectural type:** Internal construct / episode-local cognitive state of Reasoning — **not** a UAIA primitive.

---

# 3. Answers to Challenge Questions

### 1. Does ATI require a Reasoning Workspace?
**Constitutionally useful: Yes as named internal construct.**  
**As new primitive: No.**

Without a name, artifacts still “exist in Reasoning,” but boards and specializations will smuggle them into Understanding or Memory. Naming the workspace closes that gap without expanding UAIA.

### 2. If yes, what is it?
- Primitive? **No**
- Internal construct? **Yes**
- Implementation detail only? **No** — it is cognitive architecture clarity
- Cognitive state? **Yes** — episode-local state owned by Reasoning

### 3. If no, where do hypotheses live?
They would live anonymously “inside Reasoning.” Architecturally possible; politically fragile. Board prefers named ownership under Reasoning.

### 4. UAIA simplicity?
Improves ATI clarity; **does not violate UAIA** if and only if it remains internal to Reasoning and creates **no new UAIA primitive**.

### 5. Can workspace become Understanding?
**Never automatically.**  
Only if Assimilation lawfully revises Understanding from Facts — workspace speculation is not evidence. Hypotheses in workspace ≠ beliefs.

### 6. Facts / Memory / Decisions?
| Can workspace… | Ruling |
|---|---|
| Create Facts | **Never** |
| Modify Memory | **Never automatically** |
| Create Decisions | **Never** — Decision consumes citations; workspace is not Decision |

Citations from workspace into Decision rationale are **references**, not workspace survival as Memory.

### 7. What may live inside?
| Artifact | In Workspace? |
|---|---|
| Opportunity Candidates/Judgments | **Yes** |
| Predictions | **Yes** |
| Simulations / Scenarios / Counterfactuals | **Yes** |
| Explanations / Comparisons / Alternatives | **Yes** |
| Reflective notes | **Yes** |
| Understanding beliefs | **No** |
| Facts | **No** |
| Intents / Orders | **No** |

### 8. When destroyed?
| Event | Workspace fate |
|---|---|
| Reasoning Episode Closed / Halted / No-op | **Destroyed** (default) |
| Attention redirected off episode | **Destroyed or suspended-then-destroyed** — no silent immortal scratch |
| Decision made | Workspace **does not survive as living deliberation**; Decision may cite snapshots/refs |
| Explicit discard mid-flight | Discarded artifacts removed; episode may continue |

**Nothing survives automatically.** Persistence requires lawful citation or later Experience/Learning paths — not workspace immortality.

### 9. Multiple workspaces?
**Yes** — one per Reasoning Episode (scopes/horizons/theses), under Attention Control. No cross-contamination into a global “thought soup.”

### 10. Research analogues (conceptual only)
| Lens | Analogue |
|---|---|
| Cognitive science | Working memory / scratchpad for deliberation |
| Global Workspace theories | Transient broadcast contents — not long-term memory |
| DeepMind-like agents | Internal planning/search tree buffers — not world model identity |
| OpenAI-like systems | Context scratch for deliberation — not durable knowledge |
| Jane Street / quant | Research notepad / scenario book — not production book or market truth |

None require promoting scratch to world-model or production policy.

# 4. Relationships

| Relates to | Rule |
|---|---|
| **Understanding** | Premises enter workspace by **citation**, not copy-as-belief; workspace never writes Understanding |
| **Reasoning** | **Owns** the workspace entirely |
| **Decision** | May **cite** workspace outputs; selection happens outside workspace |
| **Memory** | May **retrieve into** workspace; workspace does not write Memory |
| **Learning** | Does not consume live workspace; may later consume Experiences that cited deliberation — not raw scratch |

---

# 5. Lifecycle

```
Reasoning Episode Triggered
  → Workspace Created (empty, scoped)
  → Active (artifacts added/revised)
  → Revised (artifact supersession inside episode)
  → Discarded (individual artifacts) / Halted
  → Destroyed (episode close / attention leave)
```

No “Activated” state. No “Promoted to Understanding” state.

---

# 6. Should Exist vs Should Not

## SHOULD exist (as internal construct)
- Names the home of temporary deliberation artifacts  
- Prevents Understanding/Memory pollution  
- Clarifies Opportunity/Prediction as workspace residents  
- Supports multi-episode isolation  
- Matches ATI-006 legal outputs without new primitives  

## SHOULD NOT exist (as UAIA primitive or durable store)
- Would bloat UAIA  
- Risks becoming shadow Understanding  
- Risks immortal hypothesis warehouses  
- Risks Decision-by-workspace-ranking

# 8. Final Recommendation

## **B. Add a Reasoning Workspace as an internal Reasoning construct (NOT a new UAIA primitive).**

Then **freeze ATI-006 + ATI-006R together**.

### Freeze text to append to ATI-006

> **Reasoning Workspace (internal):** Each Reasoning Episode owns a transient workspace holding its legal deliberation artifacts. The workspace is created with the episode, revised during deliberation, and destroyed when the episode closes or Attention abandons it. It never becomes Facts, Understanding, Memory, Decision, or Intent automatically. Opportunity judgments, predictions, simulations, scenarios, counterfactuals, comparisons, explanations, and reflective notes reside here while active.
