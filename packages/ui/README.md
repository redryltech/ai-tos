# @ai-tos/ui

Shared React component library (Tailwind + class-variance-authority).

## Contents
- `Button` — variant/size button.
- `cn` — Tailwind class merge helper.

## Usage
```tsx
import { Button } from '@ai-tos/ui';
<Button variant="primary">Continue</Button>
```
